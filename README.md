# PERSONAL PORTFOLIO

My portfolio site for IT ELEC 4 (Web Systems and Technologies 2) at La Consolacion University Philippines, I'm a 4th year BSIT student.

It's plain HTML, CSS and JavaScript.

## Running it

Open `index.html` in a browser, or use any static file server, like the Live Server extension in VS Code.

## Folders

- `index.html`: the page
- `css/style.css`: styles
- `js/script.js`: menu, scroll behavior, copy button
- `images/`: my photo

## Deploying

I push to GitHub and import the repo in Vercel.
